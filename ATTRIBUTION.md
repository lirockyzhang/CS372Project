# Attribution

This file lists the external libraries, datasets, references, and AI assistance used in building AlphaToe.

All third-party dependencies are declared in `pyproject.toml` and pinned in
`uv.lock`. The major ones:

| Library                | License    | Used for                                     |
|------------------------|------------|----------------------------------------------|
| [PyTorch](https://pytorch.org)            | BSD-3      | Neural networks, autograd, CUDA tensors        |
| [NumPy](https://numpy.org)                | BSD-3      | Array math, dataset I/O                        |
| [tqdm](https://github.com/tqdm/tqdm)      | MIT/MPL-2  | Progress bars in training loops                |
| [pytest](https://pytest.org)              | MIT        | Unit / integration tests                       |
| [tensorboard](https://github.com/tensorflow/tensorboard) | Apache-2 | Optional TrainingLogger sink for live curves |
| [Numba](https://numba.pydata.org/)        | BSD-2      | `numba.cuda` backend for the GPU MCTS engine   |

## Datasets
**MCTS self-play bootstrap dataset** is generated by us at training time via `data/generate_mcts_data.py`. 

Not redistributed; reproduce with the command in `README.md`.

No external / third-party game datasets are used.

## Algorithmic references

The agents implement (or adapt) ideas from the following papers. We did not use any code implementation from any of the published paper; these are simply sources of inspiration.

- Silver et al., **"Mastering the game of Go without human knowledge"**, *Nature* 2017 — AlphaZero MCTS + policy/value network.
- Danihelka et al., **"Policy Improvement by Planning with Gumbel"**, *ICLR* 2022 — basis for the simplified `alphagumbel` agent.
- Schulman et al., **"Proximal Policy Optimization Algorithms"**, *arXiv* 1707.06347 — PPO baseline.
- Vaswani et al., **"Attention Is All You Need"**, *NeurIPS* 2017 — the Transformer architecture used by the Transformer-AlphaZero variant.

## AI-assisted code
This section records the use of large language models in the project. All of the AI generated/edited code was read, understood, and tested by human
before being merged.

The following files and folders are outlined by **human** and then integrated into the codebase with the assistance of large language models (e.g., Gemini / Claude).
- ``src/agents``
- ``src/env``
- ``src/utils``
- ``src/tournament``

The following files and folders are initially drafted by the LLM, then reviewed, edited, and tested by **human**.
- ``src/scripts``
- ``src/web``

The following files and folders are written by **human** and edited by LLM for syntax and formatting purposes.  
- ``docs``
- ``README.md``
- ``SETUP.md``
- ``ATTRIBUTION.md``

The following files and folders are solely generated by non-LLM scripts and have never been edited or changed by human and/or LLM. 
- ``data``
- ``runs``
